Claude Auto Continue & Auto Resume for the Claude Code CLI — claude-auto

Hit your session limit? Go do something else. claude-auto automatically waits out the reset and continues (resumes) your Claude Code session right where you left off.

View on GitHub Install from npm

What it does

claude-auto is a transparent, drop-in wrapper around the Claude Code CLI. It runs claude inside a pseudo-terminal and forwards your keystrokes and Claude's output untouched, so the terminal looks and behaves exactly as it always has. The difference: when you hit a usage limit, it handles the wait and the resume for you.

Auto-continue when you hit a Claude usage limit

When Claude Code reports that you've hit a usage limit — your session limit, your weekly limit or your monthly spend limit — claude-auto confirms the limit via /usage, counts the reset down in your window title, and sends continue the moment your quota is back. That's the whole point: no babysitting, no lost context.

Install

npm install -g @hotox/claude-auto

Then use it as a drop-in replacement for claude:

claude-auto                    # same as `claude`
claude-auto -p "explain this"  # all args forwarded to the real CLI

Or alias claude to it so every session auto-resumes:

claude-auto --install-alias

Why claude-auto

  • Auto-resume — waits out the exact reset time from /usage, then continues automatically.
  • Auto-continue — sends continue the moment your quota returns, so long tasks keep moving.
  • Transparent wrapper — your Claude Code TUI looks and behaves exactly as before.
  • Cross-platform — works on Windows, macOS, and Linux.
  • Accurate detection — reads the rendered screen and confirms the limit against /usage to avoid false positives.
